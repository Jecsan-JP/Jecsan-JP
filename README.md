### 🚀 About me

Fullstack Developer with **6+ years** of experience. I spent almost six years building applications **end to end** — Node.js and TypeScript on AWS Lambda, relational data modeling on MySQL/RDS, and migrating legacy .NET systems to React and Next.js. Today I work on the frontend of a **fintech payments platform handling high transaction volume**.

I care about **clean architecture, maintainable code, and performance**, and I enjoy adapting solid patterns across ecosystems (yes, even a **BLoC pattern adapted to React** 😎).

- 🔭 Building **payments, checkout and identity-scoring** platforms
- 🧩 Into microfrontends, RBAC / OAuth 2.0, serverless and design systems
- 🏗️ Comfortable owning a feature from the database schema to the UI
- 💬 Ask me about React architecture, Next.js SSR, or shipping payment methods to production
- ⚡ I love turning legacy systems into clean, typed, testable code
